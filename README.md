# Power BI HR Analytics Dashboard

## Project Overview
This project presents an interactive Human Resources (HR) Analytics Dashboard built using Microsoft Power BI. It helps analyze workforce demographics, employee headcount, retention, and turnover trends to support data-driven HR decision-making.

The dashboard allows users to explore workforce metrics across different years, departments, job levels, locations, and employee demographics.

## Dashboard Pages

### 1. Headcount Analysis
- Analyzes total employee headcount over a selected timeframe.
- Compares headcount across departments and job levels.
- Examines workforce demographics by gender, age, race and ethnicity, education level, and marital status.
- Analyzes employee distribution by location, including on-site and remote work.
- Highlights departments with the highest employee counts.

### 2. Employee Retention Analysis
- Tracks employee retention trends.
- Compares retention rates across job levels and departments.
- Analyzes retention by education level and other selected categories.
- Provides starting and ending headcount for the selected period.

### 3. Employee Turnover Analysis
- Tracks employee departures and annual turnover percentages.
- Compares turnover across departments and job levels.
- Analyzes voluntary and involuntary terminations.
- Examines reasons for employee departures.
- Provides details about departing employees, including termination dates, departments, and salaries.

## Key Insights
- The headcount dashboard reports number of employees for the selected period.
- The retention dashboard shows an overall retention rate for the selected period.
- The turnover dashboard reports number of departing employees for the selected period.
- Employee retention and turnover can be compared across departments and job levels to identify areas for further investigation.
